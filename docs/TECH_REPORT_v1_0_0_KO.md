# v1.0.0 기술 보고서

## 범위
v0.8.0을 기반으로 v0.9.0에서 계획했던 게임 내 상점 기능을 포함하고, v1.0.0 첫 정식 안정화 기준으로 버전·저장 구조·PWA 캐시·Android www 소스를 통일했습니다.

## 상점
- 금화만 사용하는 반복 구매형 게임 내 상점
- 경험서, 각성석, 철광석, 가죽, 옥 5종
- 구매 수량 1~99 제한(화면에서는 1·2·3·5·10 제공)
- 금화 부족, 잘못된 상품, 비정상 수량은 거부
- 구매 시 금화 차감과 재화 지급을 새 상태 객체에서 처리
- 구매 횟수 및 누적 지출 통계 저장
- 현금 결제 및 유료 재화 연동 없음

## 저장 구조
- 저장 형식 6 → 7 마이그레이션: shop 구매 통계 필드 추가
- 기존 군주 금화, 인벤토리, 장수, 전적, 전장, 업적 데이터 보존
- JSON 백업 형식도 7로 업데이트

## 릴리스 정리
- APP_VERSION / PWA CACHE_NAME / Android package version / README 제목을 1.0.0으로 통일
- PWA 사전 캐시에 shop.js 추가
- browser-test와 Android www 파일 동기화

## 검증 한계
정적 검사와 Node 자동 테스트는 수행할 수 있으나, 실제 Android 설치·기기별 화면·실제 플레이 밸런스는 사용자 기기에서 최종 확인해야 합니다. 브라우저 GUI 자동화는 현재 실행 환경 제한으로 수행하지 않았습니다.

## 최종 검사 결과
- `node tools/verify.mjs`: 전체 정적 검사 및 기존 회귀 테스트 통과
- `node tools/test-shop.mjs`: 상점 구매·수량·재화 차감·저장 형식 마이그레이션 통과
- ZIP 무결성: 최종 패키징 후 `testzip` 오류 없음
- 브라우저 실제 화면 자동화: 실행 환경에 Playwright Chromium 실행 파일이 없어 미실시
- Android APK 빌드 및 실기기 설치: 미실시
