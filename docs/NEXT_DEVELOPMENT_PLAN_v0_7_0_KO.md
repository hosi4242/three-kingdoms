# 삼국지: 천하패권 — 비초상화 후속 개발 계획

작성 기준: v0.6.2 소스 ZIP 정적 확인 및 자동 테스트 실행 결과

## 1. 현재 구현 완료 범위

- 장수 도감 60명, 검색·세력·등급 필터, 장수 상세 정보
- 보유 장수 3명 출전, AI 3명 출전, 3판 2선승 카드 전투
- 장수별 상성, 고유 특성, 필살기, 약점 및 전투 기록
- 일반·명장·전설 모집, 등급 확률, 10회 보장, 중복 혼 조각, 전설 선택 영입
- 장수 레벨 1~30, 경험치, 경험서, 각성 5단계
- 장비 5슬롯, 5등급, 제작·장착·해제·분해, +10 강화, 세트 효과
- IndexedDB 저장, JSON 및 텍스트 백업·복원, 저장 형식 4 마이그레이션
- PWA 오프라인 캐시와 브라우저/Android www 동기화 구조

## 2. 현재 게임 진행 구조의 핵심 공백

현재 전투는 AI와 반복 대결하는 단일 자유 대전 형태다. 승리·패배 보상은 정해져 있지만, 지역·스테이지·적 세력·난이도·첫 클리어 보상·진행 잠금 해제 구조는 없다.

따라서 장비 제작과 강화를 위한 재료 수급이 전투 횟수에만 의존하고, 플레이어가 다음 목표를 선택할 장기 진행 동선도 부족하다.

## 3. 다음 버전 권장 범위: v0.7.0 전장·토벌

### 목표
기존 자유 대전을 유지하면서 별도의 PvE 전장 모드를 추가한다. 외부 서버나 온라인 기능 없이 로컬 데이터만으로 동작한다.

### 권장 초기 콘텐츠
- 3개 전장 × 5개 스테이지 = 총 15개 스테이지
- 전장 테마: 황건 잔당 토벌, 군웅 정벌, 관도 전투 전초전
- 각 스테이지는 적 세력/장수 후보군, 적 전투력 보정, 반복 보상, 최초 승리 보상을 가진다.
- 이전 스테이지를 최초 승리해야 다음 스테이지가 열린다.
- 이미 클리어한 스테이지는 반복 도전 가능하다.
- 에너지/입장권은 초기 버전에 도입하지 않는다. 오프라인 싱글플레이의 반복 파밍을 막는 불필요한 대기 요소를 피한다.

### 보상 설계 원칙
- 일반 전투의 기존 보상 규칙은 그대로 유지한다.
- 전장 반복 보상은 금화·철광석·가죽 중심으로 지급한다.
- 높은 단계에서 희귀 재료(옥)는 낮은 확률 또는 특정 단계 최초 보상으로 제한한다.
- 최초 클리어 보상은 반복 보상과 분리해 한 번만 지급한다.
- 보상은 승리 확정 시에만 지급하고 패배 시 최초 클리어 상태나 잠금 해제 상태를 변경하지 않는다.
- 보상량은 장비 제작 비용과 비교해 과도한 무한 금화/재료 파밍이 되지 않도록 테스트한다.

### 저장 데이터
- 저장 형식 4 → 5 마이그레이션 추가
- `campaign.unlockedStage` 및 `campaign.clearedStages` 형태로 진행도 저장
- 기존 금화, 장수, 레벨/경험치, 각성, 모집, 혼 조각, 장비, 전적은 모두 보존
- 구버전 백업 복원 시 캠페인 기본 진행도를 자동 생성
- 앱 데이터 버전과 저장 형식 버전을 분리하는 기존 구조 유지

### 전투 처리
- 기존 3명 출전/3판 2선승 엔진 재사용
- 자유 대전과 전장 모드의 적 팀 구성만 분리
- 전장 적 팀은 지정 세력/장수 후보에서 구성하고, 스테이지별 전투력 보정 적용
- 전투 종료 시 어떤 모드/스테이지였는지 식별해 전장 전용 보상 처리
- 전투 중 앱 새로고침/종료 시 진행 중 전투를 보상 처리하지 않도록 함

## 4. 후속 버전 순서

1. v0.7.0 전장·토벌: 스테이지 선택, 잠금 해제, 반복 파밍, 최초 보상
2. v0.8.0 임무·업적: 누적 전투/모집/강화 목표와 일회성 보상. 오프라인 날짜 변경 악용 가능성이 있는 일일 임무는 별도 검토 후 도입
3. v0.9.0 상점·재화 교환: 잉여 재료/혼 조각 활용처, 가격 밸런스, 구매 제한
4. v1.0.0 안정화: 저장/복원 회귀 테스트, 오프라인 캐시, 모바일 UI, APK 빌드 및 실기기 검증

## 5. v0.7.0 완료 판정 기준

- 15개 스테이지 잠금/해제 순서가 정확하다.
- 최초 클리어 보상은 스테이지당 한 번만 지급된다.
- 반복 클리어는 반복 보상만 지급한다.
- 패배, 전투 중 취소, 새로고침은 클리어/보상을 만들지 않는다.
- 적 팀은 스테이지 설정을 벗어나지 않는다.
- 자유 대전의 기존 보상과 전투 기록은 변경되지 않는다.
- v0.6.2 저장 데이터를 불러오면 전장 진행도가 정상 기본값으로 생성된다.
- 브라우저와 Android www의 실행 파일이 동일하다.
- 자동 테스트 통과 후에도 Android APK 빌드 및 실기기 테스트는 별도 완료로 표시한다.
