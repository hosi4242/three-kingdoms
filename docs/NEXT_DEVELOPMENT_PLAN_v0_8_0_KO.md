# 삼국지: 천하패권 — v0.8.0 이후 개발 계획

## 현재 기준
- v0.8.0 임무·업적 13종 구현 및 자동 검사 완료
- 저장 형식 6
- GitHub main 반영 및 Android 실기기 검증은 아직 미완료

## 다음 단계 권장 순서
1. v0.9.0 상점·재화 교환: 누적 플레이로 쌓이는 잉여 재료와 혼 조각의 사용처, 구매 가격, 반복 구매 제한을 설계합니다.
2. v0.9.x 콘텐츠 보완: 실제 플레이 테스트에서 확인된 보상·난이도·모바일 UI 문제를 우선 수정합니다.
3. v1.0.0 안정화: 저장/복원 회귀 테스트, 오프라인 캐시, 모바일 UI, Android APK 빌드 및 실기기 검증을 진행합니다.

## 개발 원칙
- 온라인 서버·현금 결제·에너지 대기 없이 오프라인 싱글플레이 구조를 유지합니다.
- 일일 임무처럼 기기 날짜/시간 변경으로 보상을 반복 수령할 수 있는 기능은 서버 검증 대안이 없으면 도입하지 않습니다.
- 새 저장 필드가 추가되면 저장 형식 마이그레이션과 구버전 백업 복원 테스트를 함께 추가합니다.
- 브라우저 소스를 기준으로 수정하고 Android www와 파일 단위 동기화를 유지합니다.
- 치명적 오류가 없으면 전체 프로젝트 ZIP을 생성하고, 사용자가 Windows PC에서 GitHub main으로 반영합니다.
