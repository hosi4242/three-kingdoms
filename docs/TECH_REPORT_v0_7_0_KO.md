# 삼국지: 천하패권 v0.7.0 기술 점검 보고서

## 구현 범위
- 황건 잔당 토벌, 군웅 정벌, 관도 전투 전초전: 3개 전장 × 5개 스테이지 = 15개
- 전장 진입은 기존 전투 탭에서 보유 장수 3명을 선택한 뒤 전장 탭에서 스테이지 선택
- 기존 3판 2선승 전투 엔진 재사용, 전장별 세력 적 팀 구성 및 적 전투력 보정
- 이전 스테이지 최초 승리 후 다음 스테이지 개방
- 최초 승리 보상과 반복 보상 분리, 승리 시에만 전장 재화 지급
- 패배 시 전장 진행도·전장 보상·참가 경험치 미지급
- 에너지/입장권/대기시간 없이 오프라인 반복 도전
- 저장 형식 4 → 5 마이그레이션, 기존 장수/레벨/재화/장비/전적 보존
- 서비스워커 캐시 v0.7.0, 신규 campaign.js 오프라인 캐시 포함
- 브라우저 소스를 Android www에 동기화

- Playwright 실제 브라우저 구동은 실행 환경의 네트워크 정책으로 로컬 HTTP 주소 접속이 차단되어 완료하지 못함. 정적 검사와 Node 기반 로직 테스트는 완료.
- Android APK 빌드·설치·실기기 테스트는 미실시.
- 실제 플레이 기반 난이도/보상 밸런스 테스트는 미실시.
- GitHub 커밋 및 Cloudflare 배포는 수행하지 않음.
