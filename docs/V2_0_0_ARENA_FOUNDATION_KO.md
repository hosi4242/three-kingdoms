# 삼국지: 천하패권 v2.0.0 — 아레나 기반 구현 보고서

## 이번 구현 범위
- v1.0.1의 기존 도감·모집·육성·장비·전장·업적·상점·기존 3인 전투를 보존하는 별도 아레나 메뉴를 추가했습니다.
- 4대4 AI 대전 편성 및 전투 시뮬레이터를 추가했습니다.
- 장수 60명의 기존 무력·지력·통솔·등급·레벨·각성 정보를 바탕으로 HP / ATK / DEF / SPD / 치명타 확률을 산출합니다.
- 장수 카드에 HP, ATK, DEF, SPD, 고유 효과 유형과 전투 중 활성 상태 효과를 표시합니다.
- 공격형은 기절/맹공, 전술형은 속도 감소/책략, 진형형은 보호막/진형 효과를 우선 부여합니다.
- 보호막, 공격력 증가, 지속 피해, 속도 감소, 기절을 전투 엔진에 구현했습니다.
- 속도 기반 행동 순서, HP 비율 기반 표적 선택, 치명타, 피해량 및 전투 로그를 구현했습니다.
- 승리 시 아레나 포인트 20점을 지급하고 승/패/포인트를 기존 저장 데이터에 추가합니다.
- 기존 저장 형식 7을 변경하지 않고 `arena` 기본 필드만 정규화하므로 기존 저장 데이터 마이그레이션이 필요하지 않습니다.
- 카드의 짧은 등장 이동과 HP 바 전환만 사용합니다. 화려한 이펙트·전장 애니메이션은 사용하지 않습니다.

## 기술검사
- `node tools/verify.mjs`: 통과
- `node tools/test-arena.mjs`: 60명 능력치 생성, 4대4 팀 구성, 100회 전투, 상태 효과 로그, HP 범위, 종료 조건 통과
- 기존 모집·육성·기존 전투·장비·전장·업적·상점·초상화 테스트 모두 통과
- Browser와 Android `www` 소스 파일 목록 및 내용 일치 검사 통과

## 현재 한계 및 다음 구현 항목
1. 개별 장수 고유 액티브/패시브 스킬은 아직 성향별 효과 템플릿 단계입니다. 장수별 고유 스킬 데이터로 분리해야 합니다.
2. 아레나 상대는 현재 보유하지 않은 장수 중 전투력 상위 4명을 자동 편성합니다. 난이도 구간 및 상대 편성 저장 기능은 후속 작업입니다.
3. 전투는 로그를 포함한 자동 시뮬레이션 결과를 한 번에 보여줍니다. 한 턴씩 진행하는 수동 재생/속도 조절은 후속 작업입니다.
4. 장비의 세부 HP/ATK/DEF/SPD 부옵션과 세트 효과는 아직 아레나 능력치에 완전히 반영하지 않았습니다.
5. Chromium 실행 환경이 없어 실제 브라우저 렌더링 및 모바일 터치 테스트는 수행하지 못했습니다. 정적 검사와 엔진 시뮬레이션 검증만 완료했습니다.
6. 기존 v1.0.1의 초상화 30/60명 상태는 그대로이며, 나머지 30명 초상화는 미제작 상태입니다.
