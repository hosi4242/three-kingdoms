# 삼국지: 천하패권 기술 검사 보고서 (v0.4.0 검토 및 v0.5.0 개발)

작성 기준: 제공된 Claude v0.4.0 ZIP 및 `samgukji-TECH_REPORT_KO.md`를 검토한 뒤 v0.5.0 작업본을 생성하고, 포함된 자동 검사 도구를 실행했습니다.

## 1. v0.4.0 인수 검사 요약

제공된 기술 보고서에 따르면 v0.4.0은 다음 문제를 수정했습니다.
- AI가 플레이어의 선택 카드를 보고 상성 카운터를 선택하던 문제
- AI가 플레이어의 3명 출전 규칙과 달리 전체 장수에서 매 라운드 출전자를 선택하던 문제
- 백업 복원 검증 부족 및 손상 데이터 덮어쓰기 위험
- 저장 데이터 마이그레이션 무한 반복 위험
- 서비스워커 캐시 갱신, HTML 이스케이프, 모바일 터치 및 화면 표시 문제
- 일반 등급 장수 부재 문제(일반 등급 10명 추가)

Claude 보고서에서 실제 Android 기기 및 APK 빌드는 미검증으로 명시되어 있었습니다.

## 2. v0.4.0에서 다음 단계 전 해결한 항목

보고서의 U1에 따라 장수별 필살기·특성·약점이 스타일별 고정 수치로 계산되는 문제를 우선 보완했습니다.
- 60명 각각 `combatEffects` 데이터를 갖도록 변경
- 특성: 적용 능력치와 개별 계수
- 필살기: 개별 기본 보너스와 상성 우위 추가 보너스
- 약점: 개별 약점 성향과 페널티
- 전투 계산을 `js/combat.js`로 분리하여 단위 검사 가능하게 구성
- 검사 결과 전투 효과 데이터 조합 60종 모두 고유

## 3. v0.5.0 신규 구현

### 장수 성장
- 장수 레벨 1~30
- 현재 레벨 × 100을 다음 레벨까지 필요한 경험치로 적용
- 경험서 1개 사용 시 경험치 100
- 경험치가 기준치를 넘으면 자동으로 연속 레벨업
- 최대 레벨에서는 추가 경험치 누적을 중단

### 전투 보상
- 전투 승리 시 금화 150 및 경험서 1개
- 전투 패배 시 금화 60
- 해당 전투에 선택한 보유 장수 3명에게 승리 시 경험치 40, 패배 시 경험치 20 지급
- 누적 전투 승리 3회마다 각성석 1개 지급

### 각성
- 장수별 최대 5단계
- 각성 1회당 각성석 3개 소비
- 각성 1단계당 전투력 +3
- 미보유 장수, 재료 부족, 최대 단계 초과는 거부
- 각성 계산 함수는 입력 저장 객체를 직접 변경하지 않도록 구성

### 기존 데이터 호환
- 저장 형식 2(v0.4.0)에서 형식 3(v0.5.0)으로 자동 변환
- 기존 보유 여부, 장수 레벨/경험치, 금화, 모집 천장, 혼 조각, 전적 유지
- 기존 저장에 경험서가 없으면 3개, 각성석이 없으면 0개로 초기화
- 저장 변환은 깊은 복사를 사용해 원본 입력 객체를 변경하지 않음

## 4. 검사 결과

`node tools/verify.mjs` 실행 결과: **모든 정적 검사 통과**

검사 범위:
- 브라우저 및 Android www JavaScript 문법 검사
- 장수 60명, ID/이름 중복 여부
- 등급별 장수 수 및 모집 등급 충족 여부
- 장수별 전투 효과 데이터 존재 및 60개 조합 고유성
- 앱 버전, 서비스워커 캐시 버전, package.json, HTML 표시, 폴더명 일치
- PWA 캐시 목록, 아이콘, 파일 참조 및 모듈 import 경로
- 브라우저와 Android www의 파일 목록 및 바이트 내용 일치(14개 파일)
- 모집 확률·10회 보장·중복 혼 조각·전설 영입·금화 차감·저장 형식 변환 테스트
- 레벨·경험치·각성 테스트
- 전투력·특성·필살기·약점 효과 테스트

모집 확률 시뮬레이션은 각 모집별 자연 확률 50,000회 표본으로 확인했으며, 관측치는 목표 확률에서 최대 약 0.30%p 차이였습니다. 10회 보장 테스트는 각 배너 500회, 단건 누적 테스트는 각 배너 8,000회 실행했고, 보장 등급 연속 미출현은 최대 9회였습니다. 최악 난수 테스트에서도 10·20번째에 보장이 발동했습니다.

추가 단위 검사:
- 경험치 100으로 Lv.2 도달
- Lv.30 상한
- 각성석 3개 소비 및 1단계 상승
- 존재하지 않는 장수, 재료 부족, 최대 각성 단계 거부
- 잘못된 진행 데이터 상한 보정
- 60명 전투력·특성·필살기 계산 유효
- 약점 대상별 페널티 적용
- 상성 우위 필살기 추가 보너스 적용
- 각성 단계당 전투력 +3

## 5. 검사 한계 및 미해결 사항

- Playwright 브라우저 런타임 검사는 Chromium 실행 파일이 현재 환경에 없어 실행하지 못했습니다.
- 실제 Android APK 빌드, 설치, 저장, 파일/텍스트 백업·복원은 미실시입니다.
- HTTPS 배포 환경 및 오프라인 실기기 검증은 미실시입니다.
- iOS Safari, 가로 모드, 태블릿, 스크린리더, Android 뒤로가기 동작은 미검증입니다.
- 필살기 발동 비용·횟수 제한은 아직 없으며, 사용 여부의 전략적 비용을 추가할지는 게임 규칙 결정이 필요합니다.
- AI의 난이도는 플레이어 전력에 따라 단계적으로 조절하지 않습니다.
- 모집 비용과 혼 조각 환산값은 임시 밸런스 값이며 실제 플레이 후 조정이 필요합니다.
- 서비스워커 업데이트 직후 첫 화면이 이전 버전일 수 있어 새 버전 알림 UI가 필요합니다.
- Capacitor 설정의 `bundledWebRuntime` 호환 여부와 Android 도구 버전은 별도 공식 문서 확인 및 실제 빌드가 필요합니다.
- 등급과 능력치 총합의 범위가 일부 겹칩니다. 등급만으로 전투력을 단정하지 않도록 유지하되 밸런스는 추가 검토가 필요합니다.

```bash

node tools/test-recruit.mjs
node tools/test-progression.mjs
node tools/test-combat.mjs
```
