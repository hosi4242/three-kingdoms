# 삼국지: 천하패권 v0.6.0 dual 기술 검사 보고서

## 1. 버전 및 기준
- 기준 버전: v0.5.0 dual (저장 형식 3)
- 현재 버전: v0.6.0 dual (저장 형식 4)
- 브라우저 원본: `browser-test/`
- Android WebView 배포 소스: `android-apk-project/www/`
- 본 버전은 장비 시스템을 추가하며 기존 모집·성장·각성·전투 기능을 유지합니다.

## 2. 구현 내용
- 장비 슬롯 5종: 무기, 갑옷, 군마, 보물, 병법서
- 장비 등급 5종: 일반, 고급, 희귀, 영웅, 전설
- 25개 장비 기본 레시피, 청룡·백호·현무·주작 세트
- 장비 제작, 장수별 장착/해제, 분해
- 강화 +1~+10: 강화 실패·장비 파괴 없이 비용 충족 시 확정 강화
- 세트 효과: 같은 세트 2/3/5개 장착 시 단계별 능력치/전투력 보너스
- 장비 능력치 및 세트 효과를 전투력 계산에 반영
- 전투 승리 보상: 철광석 2, 가죽 1 추가
- 전투 패배 보상: 철광석 1 추가
- 저장 형식 3 → 4 마이그레이션: 기존 장수/금화/경험/각성/모집 데이터 유지, 장비 보관함과 슬롯 초기화
- PWA 오프라인 캐시에 `equipment.js` 포함
- 브라우저와 Android `www` 소스 동기화

## 3. 제작 및 강화 밸런스
- 제작 기본 비용: 일반 금화 100/철광석 8부터 등급별 증가
- 고급 이상 제작 시 가죽 추가 소모
- 전설 제작 시 옥 2개 추가 소모
- 강화 비용: 금화 `100 + 현재 강화 단계 × 100`, 철광석 `2 + 현재 강화 단계`
- 장비 파괴 없음. 비용 부족 시 원본 저장 상태 변경 없음.
- 분해 시 철광석 반환, 등급에 따라 가죽/옥 일부 반환

## 4. 자동 검사 결과
`node tools/verify.mjs` 검사 항목:
- 브라우저/Android JavaScript 문법
- 장수 60명, ID/이름 중복 및 핵심 데이터
- 앱/서비스워커/package/HTML/README 버전 일치
- PWA 파일 캐시 및 import 경로
- 브라우저 ↔ Android `www` 파일 목록/내용 일치
- 기존 모집 확률/천장/혼 조각/저장 변환 테스트
- 장수 육성 및 전투 효과 테스트
- 신규 장비 슬롯/제작/장착/강화/해제/분해/세트 효과/저장 형식 3→4 테스트

검사 실행 결과: **모든 정적 검사 및 자동 테스트 통과**.

## 5. 미검증 및 제한 사항
- 실제 브라우저 GUI 조작 및 화면 레이아웃은 Chromium 실행 환경이 없어 자동 실기 테스트하지 못했습니다.
- 실제 Android APK 빌드, 설치, 실기기 저장/백업/복원 검증은 수행하지 않았습니다.
- GitHub 커밋 및 Cloudflare 자동 배포는 이 보고서 작성 시점에 수행하지 않았습니다.
- 장수 초상화는 기존 한자 이니셜 표시를 유지합니다. 코에이 『삼국지 11』 원본 이미지는 저작권 허가가 확인되지 않아 포함하지 않았습니다. 사용 허가가 있는 파일 또는 별도 제작한 오리지널 초상화가 확보되면 별도 반영할 수 있습니다.
- 장비 수치와 제작 비용은 초기 밸런스이며 실제 플레이 테스트 후 조정이 필요합니다.

## 6. 실행
프로젝트 루트에서:
```bash
node tools/verify.mjs
```
브라우저 테스트 폴더는 HTTPS 정적 호스팅으로 실행합니다. Android APK는 `android-apk-project/README_KO.md` 절차에 따라 별도 빌드합니다.
