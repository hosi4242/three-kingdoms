# v1.0.0 초상화·모바일 UI·UX 재점검 보고서

## 1. 장수 초상화

- 장수 데이터: 60명
- 실제 WebP 초상화: 30개 (모두 256×320, RGB, 파일 디코딩 검사 통과)
- 이미지가 연결된 장수: 30명
- 이미지가 없는 장수: 30명
- 초상화가 없는 장수는 `app.js`의 `portraitHTML()`에서 이름 첫 글자 대체 카드로 표시됩니다. 따라서 null 초상화 때문에 HTML 이미지 요청이 깨지는 구조는 아닙니다.
- 기존 이미지 30개를 시각적으로 확인했으며, 전반적으로 세로형 인물 일러스트 스타일입니다. 일부 배경/색감 차이는 향후 신규 이미지 제작 시 통일하는 것이 좋습니다.

### 향후 이미지 제작 기준

1. 기존 에셋과 같은 4:5 세로 비율(권장 256×320 또는 고해상도 원본 후 WebP 변환)을 유지합니다.
2. 삼국지 시대풍의 반실사 디지털 페인팅, 인물 중심 상반신 구도, 얼굴이 잘 보이는 조명과 배경을 통일합니다.
3. 각 장수의 세력·역할·복식·무기·연령 인상을 구분하되, 역사적 인물의 초상화를 그대로 복제하지 않는 독창적 디자인을 사용합니다.
4. 생성 후 인물 중복, 손·무기·얼굴 왜곡, 잘림, 파일명과 장수 ID 매칭을 검수합니다.
5. `browser-test/assets/portraits/`에 넣은 뒤 동일 파일을 `android-apk-project/www/assets/portraits/`에도 복사하고 두 폴더를 바이트 단위로 비교합니다.
6. `browser-test/js/generals.js`의 해당 장수 `portrait`를 정확한 경로로 지정하고, `browser-test/sw.js`의 `APP_FILES`에 추가합니다.
7. 서비스워커 캐시 버전과 앱 버전을 올린 후 Android `www` 동기화 및 전체 검사를 실행합니다.

## 2. 초상화 표시 UX

- 현재 이미지가 있는 장수는 `<img>`로 표시하며 `loading="lazy"`, `decoding="async"`를 사용합니다.
- 이미지가 없는 장수는 이름 첫 글자로 대체합니다.
- 모집 결과 UI는 현재 초상화 이미지를 사용하지 않고 이름 첫 글자 대체 표시를 사용합니다. 향후 초상화 완성 시 모집 결과 카드도 공통 초상화 렌더링 함수를 사용하도록 개선할 것을 권장합니다.
- 상세 화면과 장수 도감/육성 카드의 초상화 표시 크기는 서로 다르며 object-fit cover를 사용합니다.

## 3. 모바일 UI/UX 정적 점검

- viewport 메타 태그와 `viewport-fit=cover`가 설정되어 있습니다.
- CSS에 `box-sizing:border-box`, 작은 화면용 필터·전투·캠페인·상점 레이아웃 분기, 하단 safe-area padding이 있습니다.
- 버튼의 최소 높이 44px 규칙과 터치 조작 최적화가 일부 적용되어 있습니다.
- 상단 탭과 하단 메뉴 모두 가로 스크롤 구조입니다. 하단 메뉴는 10개 항목이고 각 항목 최소 폭이 56px이므로 360~390px 화면에서 모든 메뉴가 한 번에 보이지 않습니다. 좌우 스크롤이 가능하지만 스크롤 가능성이 눈에 잘 띄지 않을 수 있습니다.
- 따라서 장기적으로 하단 메뉴는 핵심 4~5개 + '더보기' 메뉴로 재구성하거나, 현재 구조를 유지하되 스크롤 안내/선택 상태 가시성을 강화하는 것이 좋습니다.
- 상점 구매 수량 선택 컨트롤은 CSS에서 높이 38px로 지정되어 있어 44px 터치 권장치보다 작습니다. 모바일 접근성 개선 시 44px 이상으로 키우는 것이 좋습니다.

## 4. 실제 UI 실행 테스트의 한계

Chromium 실행 파일은 환경에 존재하지만, 이 실행 환경의 브라우저 네비게이션 정책이 `http://127.0.0.1` 접근을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단했습니다. 따라서 모바일/데스크톱 화면 렌더링, 실제 탭 클릭, 스크롤, 터치 타깃 좌표 및 콘솔 오류를 이번 실행에서 직접 확인하지 못했습니다.

Android APK 빌드 및 실기기 테스트도 아직 수행하지 않았습니다. 실제 모바일 UX가 완전히 검증됐다고 판단하면 안 됩니다.

- 브라우저와 Android `www`의 전체 파일/내용 일치 검사를 다시 수행합니다.
