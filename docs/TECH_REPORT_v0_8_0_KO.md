## 제한 및 미완료
- 실행 환경 정책으로 실제 브라우저 GUI 구동 테스트는 완료하지 못함.
- Android APK 빌드·설치·실기기 테스트는 미실시.
- 난이도 및 보상 밸런스는 실제 플레이 데이터를 통한 검증이 필요함.
- GitHub 커밋 및 Cloudflare 배포는 아직 수행하지 않음.

## 저장 데이터 호환성
- v0.7.0의 저장 형식 5를 v0.8.0의 형식 6으로 자동 변환합니다.
- 기존 금화, 장수, 경험치, 모집 이력, 장비, 전적, 전장 진행도를 유지합니다.
- 기존 데이터의 누적 수치가 임무 목표에 이미 도달한 경우, 최초 실행 시 해당 업적을 완료 처리하고 보상을 한 번 지급합니다.
