# 삼국지: 천하패권 v0.6.2 초상화 확장 기술 보고서

## 작업 내용
- 조조 초상화를 궁궐·전장 배경이 분명한 이미지로 교체했습니다.
- 기존 5명에 더해 25명의 초상화를 추가해 총 30명에 이미지 경로를 연결했습니다.
- 나머지 30명은 아직 미적용이며 기존 이니셜 표시를 유지합니다.
- 모든 초상화는 256×320 WebP, 품질 73으로 저장했습니다.
- 브라우저와 Android www에 동일한 이미지 파일을 복사했습니다.
- 서비스워커 캐시를 v0.6.2로 갱신하고 30개 이미지를 캐시 목록에 추가했습니다.
- 저장 데이터 형식은 변경하지 않았습니다.

## 용량
- 적용 초상화: 30장
- 초상화 총 용량: 484,460 bytes (473.1 KB)
