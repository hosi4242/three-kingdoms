# 버전 2.0.2 변경 사항

## 아레나 장수 카드 개편
- 아레나 전투 카드에서 장수 초상화를 제거했습니다. 기존 초상화 파일과 일반 장수 화면의 초상화 기능은 보존했습니다.
- 카드 앞면은 한글 중심으로 장수 이름, 소속, 등급, 체력, 공격·방어·속도, 핵심 스킬 효과와 현재 상태만 표시합니다.
- 자세한 고유 기술·지속 특성·약점 설명은 카드 뒷면으로 이동했습니다.
- 카드 가장자리에 앞면/뒷면 전환 버튼을 추가했습니다.
- 모바일 4대4 배치를 고려해 양 팀을 나란히 표시하고, 각 팀 카드를 2열 2행으로 배치합니다.
- 위·촉·오·군웅 소속별 색상과 금색 테두리, 은은한 무늬를 적용했습니다.
- 저장 데이터 형식은 변경하지 않았습니다.
