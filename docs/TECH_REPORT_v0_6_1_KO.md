# 삼국지: 천하패권 v0.6.1 초상화 적용 기술 보고서

## 1. 작업 범위
- 기준 프로젝트: v0.6.0 dual
- 변경 버전: v0.6.1 dual
- 사용자 승인 시범 그림체를 바탕으로 초상화 기능을 추가했습니다.
- 이번 패키지에는 대표 장수 5명(관우, 장비, 조조, 유비, 제갈량)의 초상화만 포함되어 있습니다. 나머지 55명은 개별 초상화 제작 및 적용이 아직 완료되지 않았으며, 기존 이니셜 표시로 유지됩니다.

## 2. 이미지 최적화
- 크기: 256 × 320 픽셀
- 형식: WebP
- 인코딩 품질: 73
- 실제 개별 파일: 5개, 총 실제 파일 크기는 ZIP 내부 `browser-test/assets/portraits/`에서 확인 가능
- 파일명: 장수 ID 기반 (`gen_001.webp` 등)
- 이미지 파일은 브라우저와 Android `www`에 동일하게 복사했습니다.

## 3. 적용 화면 및 오프라인 지원
- 장수 도감 카드
- 장수 상세 화면
- 장수 육성 화면
- PWA 서비스워커 캐시에 이미지 5개 등록
- 이미지가 없는 장수는 기존 한자 이니셜로 안전하게 표시하도록 fallback 유지

## 4. 변경된 버전
- APP_VERSION / 화면 표시 / Android package version / Service Worker cache: 0.6.1
- 저장 형식은 기존 4를 유지했습니다. 기존 저장 데이터 마이그레이션은 필요하지 않습니다.

## 5. 자동 검사
- `node tools/verify.mjs`: 모든 정적 검사 및 기존 모집·육성·전투·장비 테스트 통과
- JavaScript 문법 검사 통과
- 장수 60명 및 데이터 무결성 검사 통과
- 브라우저와 Android `www` 파일 일치 검사 통과
- PWA 이미지 경로 및 오프라인 캐시 파일 존재 검사 통과
- ZIP 무결성 검사는 별도 실행

## 6. 미완료 및 미검증 사항
- 60명 중 5명 초상화만 적용, 나머지 55명은 후속 제작 대상
- 실제 브라우저 GUI 조작 및 실제 Android APK 빌드·설치·실기기 테스트는 수행하지 않았습니다.
- GitHub 커밋 및 Cloudflare 자동 배포는 수행하지 않았습니다.
- 생성된 오리지널 이미지 외 인터넷 이미지의 무단 사용은 포함하지 않았습니다.
