# 삼국지: 천하패권 v2.0.1 변경 기록

## 이번 단계: 장수별 고유 스킬 및 효과 세분화
- 60명 장수의 기존 고유 필살기 이름·설명을 아레나 카드와 전투 로그에 연결했습니다.
- 고유 스킬 발동 시 장수 ID 기반 스킬 효과 유형을 배정합니다: 기절, 속도 감소, 지속 피해, 공격력 증가, 보호막, 공격력 약화.
- 스킬 재사용 대기시간을 추가했습니다.
- 기존 장수별 전투 특성 데이터를 아레나 능력치 계산에 반영했습니다.
- 속도 감소는 SPD 비율 감소로 계산합니다.
- 카드에 고유 스킬명과 설명을 표시하고, 짧은 반응 효과만 유지했습니다.
- 저장 형식은 7을 유지하며 기존 저장 데이터 마이그레이션은 필요하지 않습니다.
- 브라우저와 Android www 소스를 동기화했습니다.

- 기존 모집·육성·전투·장비·전장·임무·상점·초상화 테스트: 통과
