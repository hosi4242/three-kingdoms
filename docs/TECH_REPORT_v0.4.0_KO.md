# 삼국지: 천하패권 기술 검사 보고서 (v0.3.0 → v0.3.1 → v0.4.0)

검사 환경: Node.js 22, Chromium(Playwright, 모바일 360×740 에뮬레이션). **실제 Android 기기·APK 빌드는 확인하지 못했습니다.**

## 0. 인수 시 확인한 사항
- ZIP 이름은 `v0_3_0`이지만 내부 폴더는 `samgukji-cheonhap_v0_1_1_dual`, `package.json` 버전은 0.1.1이었습니다. 코드 내용은 v0.3.0이 맞았습니다. (v0.3.1부터 버전·폴더명 통일)
- 원본 상태에서 `browser-test`와 `android-apk-project/www`의 앱 파일은 동일했습니다.

## 2. 미해결 문제 / 판단이 필요한 사항 (수정하지 않음)
- U1 필살기·특성·약점이 장수별 고유 효과가 아닙니다. 설명 문구는 스타일별 3종 템플릿이고 전투 수치도 스타일별 고정값입니다. 일부 문구(공격형 필살기의 "진형형에게 효과 감소", 전술형 특성의 "상성 완화")는 코드에 구현되어 있지 않습니다. 장수별 효과 데이터화는 v0.5.0(레벨·각성) 이전에 하는 것을 권장합니다.
- U2 필살기에 비용·횟수 제한이 없어 매 라운드 켜는 것이 항상 이득입니다(각 장수는 1번만 출전). 규칙 변경이라 손대지 않았습니다.
- U3 **Android 실기기 미확인**: APK 빌드, 파일 백업 저장(Blob 다운로드는 WebView에서 막힐 가능성), 파일 복원 선택기. 대체 수단으로 텍스트 복사/붙여넣기 백업을 추가했으나 실기기 확인이 필요합니다.
- U4 `android/` 폴더는 `npx cap add android` 최초 실행 시 생성됩니다. 앱 서명·아이콘·appId(`com.cheonhap.game`) 확정 필요. Capacitor 7의 Node/JDK/Android Studio 요구 버전은 공식 문서로 확인이 필요합니다.
- U5 AI 상대는 전체 장수 균등 추첨이라 플레이어 전력과 무관합니다(난이도 조절 없음). 시작 전설 5명으로 라운드 승률 약 65%입니다.
- U6 모집 비용(금화)·혼 조각 환산값은 제가 임의로 정했습니다. 전투 승리 보상 150금과의 균형은 실제 플레이로 조정하세요. (`js/recruit.js` 상단)
- U7 서비스워커 특성상 업데이트 후 첫 실행은 옛 화면이고, 한 번 더 열면 새 버전입니다. 새 버전 알림 UI는 없습니다.
- U8 `capacitor.config.json`의 `bundledWebRuntime`은 최신 Capacitor에서 사용되지 않는 옵션일 수 있습니다(미검증).
- U9 등급과 능력치 합계가 겹칩니다(고급 최대 387 > 희귀 최소 309). 일반 등급 신규 10명의 이름·능력치는 새로 만든 값이므로 검토가 필요합니다.
- U10 iOS Safari, 가로 모드, 태블릿, 접근성(스크린리더), Android 뒤로가기 버튼 동작은 점검하지 않았습니다.

## 4. v0.4.0 모집 시스템 검증 수치
- 자연 확률(보장 발동 전 모집 30만 회씩): 일반 모집 55.03/29.98/11.99/3.00%, 명장 65.04/27.02/7.94%, 전설 74.94/25.06% (목표 대비 오차 0.07%p 이내)
- 10회 보장은 "마지막 보장 등급 이후 9회 연속 미달이면 10번째는 확정" 방식으로, 횟수는 저장됩니다. 최악 난수에서도 10·20번째에 발동, 4만 회 연속 단건 모집에서도 연속 미출현 최대 9회입니다.
- 보장 때문에 실제 보장 등급 이상 비율은 표보다 약간 높습니다 (일반 모집 고급↑ 45.1%, 명장 영웅↑ 35.4%, 전설 모집 전설 26.5%).
- 금화 부족·저장 실패 시 금화/장수 모두 변경되지 않음, 더블탭 시 1회만 실행, 전설 혼 조각 99개 영입 불가·100개 영입 가능 확인.
