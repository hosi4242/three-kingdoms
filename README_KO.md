# 삼국지: 천하패권 v0.5.0 — 브라우저 + Android APK 제작 소스

## v0.5.0 신규 기능
- 장수 레벨 1~30, 경험치 누적 및 자동 레벨업
- 경험서 1개 사용 시 경험치 100 획득
- 전투 승리 시 경험서 1개, 참가 장수 3명에게 경험치 40씩 지급 (패배 시 경험치 20씩)
- 전투 3회 승리마다 각성석 1개 획득
- 각성 최대 5단계, 단계당 전투력 +3, 각성석 3개 소비
- 장수별 개별 전투 효과 데이터: 특성 계수, 필살기 기본/상성 보너스, 약점 대상 및 페널티
- 기존 v0.4.0 모집·확률·천장·혼 조각·전설 영입 유지

## 기술/저장 데이터
- 저장 형식 3: v0.4.0(형식 2)에서 자동 변환
- 기존 보유 여부·장수 레벨·경험치·금화·모집 천장·혼 조각·전적을 유지
- 기존 저장에 경험서 3개를 최초 보완 지급, 각성석은 0개로 시작
- `browser-test`를 원본으로 수정하고 `tools/SYNC_TO_ANDROID.bat` 또는 `tools/sync-android.sh`로 Android www에 동기화

## 검사
- `node tools/verify.mjs` : 문법·데이터·버전·PWA·브라우저/Android 동기화 및 모집 테스트
- `node tools/test-progression.mjs` : 레벨·경험치·각성 테스트
- `node tools/test-combat.mjs` : 장수별 특성·필살기·약점 계산 테스트
- Android APK 실제 빌드/기기 설치는 별도 수행 필요

## 기존 기능 유지
- 장수 도감 60명, 검색/필터, 상세 정보
- 3명 출전, 3판 2선승, AI 3명 출전, 상성 및 전투 기록
- 일반/명장/전설 모집, 10회 보장, 중복 혼 조각, 전설 선택 영입
- IndexedDB 저장, JSON/텍스트 백업 및 복원

## 주의
- 장수 능력치와 전투 효과는 게임 밸런스용 창작값입니다. 원작 삼국지 13의 공식 수치나 이미지가 아닙니다.
- 브라우저 저장 공간과 Android 앱 저장 공간은 서로 자동 동기화되지 않습니다. 기기 변경 전 백업하세요.
- 실제 Android APK 빌드/실기기 테스트는 아직 완료되지 않았습니다.
