# 삼국지: 천하패권 v1.0.0 브라우저 실행판

브라우저에서 실행하는 모바일 우선 카드 전략 게임입니다. `index.html`을 로컬 서버 또는 배포 주소에서 열어주세요.

## v1.0.0 주요 기능
- 장수 수집·모집·육성·각성·장비·전투·15단계 전장
- 누적 임무·업적 13종 및 일회성 자동 보상
- 금화만 사용하는 상점 5종(현금 결제 없음)
- JSON 파일 및 텍스트 백업·복원
- 저장 형식 6 → 7 자동 변환

전체 검사 및 Windows 업로드 절차는 프로젝트 루트의 `README_KO.md`와 `docs/`를 참고하세요.
